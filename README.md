# PostCraft AI – Intelligent LinkedIn Post Generator

PostCraft AI is an AI-powered system that generates high-quality LinkedIn posts based on a user’s writing style using LLMs like Groq and LangChain.

## Built By
vamsimeenan

## What I Built
- Designed prompt engineering pipeline for post generation
- Integrated Groq LLM for fast inference
- Implemented few-shot learning for writing style matching
- Built Streamlit-based user interface

## Key Features
- AI-powered LinkedIn post generation
- Style-based content replication
- Topic-aware content generation
- Fast LLM responses

## Tech Stack
- Python
- LangChain
- Groq LLM
- Streamlit

## Impact
Reduces LinkedIn content creation time by up to 80% using AI automation.
