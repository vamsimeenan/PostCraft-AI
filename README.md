# 🌟 Introduction

PostCraft AI is an advanced AI-powered LinkedIn post generation platform designed to help users create high-quality professional content in seconds.

The application leverages:
- **Llama 3.2**
- **LangChain**
- **Groq API**
- **Few-Shot Prompt Engineering**
- **Streamlit**

to generate personalized LinkedIn posts that replicate a user's writing style, tone, and structure.

This project demonstrates:
- LLM Workflow Design
- Prompt Engineering
- Few-Shot Learning
- AI Content Generation
- Full Stack AI Application Development

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/vamsimeenan/PostCraft-AI.git
```

---

## 2️⃣ Navigate to Project

```bash
cd PostCraft-AI
```

---

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Configure Environment Variables

Create `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```

---

## 6️⃣ Run Application

```bash
streamlit run app.py
```
